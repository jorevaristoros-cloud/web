
# NOVACORE AI

## Descripcion del proyecto

NOVACORE AI es una pagina web ficticia dedicada a la
inteligencia artificial, la automatizacion y la innovacion
tecnologica.

## Objetivo

Presentar servicios tecnologicos mediante una pagina web
sencilla, moderna y adaptable a diferentes dispositivos.

## Tecnologias utilizadas

- HTML5
- CSS3
- YouTube iframe
- Multimedia local

## Caracteristicas

- Menu de navegacion interna
- Seccion de inicio
- Informacion sobre la empresa
- Tarjetas de servicios
- Video de YouTube
- Audio y video locales
- Seccion de contactos
- Animacion CSS
- Dos media queries para adaptar el diseno
- Metadatos basicos para SEO

## Archivos del proyecto

- index.html: estructura y contenido.
- estilos.css: diseno y estilos visuales.
- README.md: documentacion del proyecto.
- imagenes/: imagenes utilizadas.
- multimedia/: archivos de audio y video.
